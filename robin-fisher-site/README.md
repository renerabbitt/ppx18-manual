# Robin Rigby Fisher website concept

Responsive single-page portfolio concept for Robin Rigby Fisher, CMKBD, CAPS, CLIPP.

## Preview
Open `index.html` locally, or configure GitHub Pages / a static host to publish this directory.

## Image note
The project names and portfolio destinations were researched from Robin Rigby Fisher's publicly published Houzz portfolio. The hero currently attempts to load a published Houzz image URL and falls back gracefully; remaining project tiles intentionally use art-directed placeholders linked to the corresponding published project pages. Before a production launch, place licensed/approved copies of Robin's project photography in an `images/` directory and replace the `.media-*` background declarations in `styles.css`. This avoids copying third-party-hosted photography into this repository without confirmed image rights.
